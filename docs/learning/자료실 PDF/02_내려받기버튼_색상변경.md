# 02. 자료실 "문서 내려받기" 버튼 색상 변경

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 버튼 색을 바꿀 때 디자인 토큰 규칙을 어떻게 지키는지 이해한다.
> 작성: 2026-10-05 · 오현명
> 📘 개념 설명(용어·코드 의미·최종 구조)은 `03_자료실_개념설명.md` 참고.

---

## 1. 요약

- 자료실 각 줄 오른쪽 끝 **"문서 내려받기" 버튼을 빨간색**(흰 글씨)으로 바꿨다. 마우스를 올리면 조금 더 진한 빨강이 된다.
- 프로젝트 규칙(하드코딩 hex 금지)에 따라 `design-tokens.css` 에 **빨간색 토큰 2개를 추가**하고 버튼은 토큰만 사용한다.
- 색은 실습 화면(DVWA 재현)의 빨간 Submit 버튼과 같은 계열이다.

---

## 2. 개념 설명 (비유)

**페인트 색 견본표**와 같다.

- 벽(버튼)에 직접 색 번호를 적지 않고, 견본표(디자인 토큰)에 "강조 빨강"을 등록한 뒤 그 이름으로 칠한다.
- 나중에 빨강을 바꾸고 싶으면 견본표 한 곳만 고치면 모든 버튼에 반영된다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| 디자인 토큰 | 색·간격 등 디자인 값을 이름 붙여 모아 둔 CSS 변수 (`--sq-*`) |
| hover | 마우스를 요소 위에 올린 상태 |

---

## 4. 화면 & 동작

```
[초급] Command Injection                     [ 📄 문서 내려받기 ]  ← 빨간 배경 · 흰 글씨
       입력값에 OS 명령을 주입해 ...                  (hover 시 더 진한 빨강)
```

| 토큰 | 값 | 용도 |
|---|---|---|
| `--sq-color-danger` | `#DD3333` | 강조 버튼 배경·테두리 |
| `--sq-color-danger-hover` | `#C42B2B` | hover 시 배경 (danger 10% darken) |
| `--sq-color-on-accent` | `#FFFFFF` (기존) | 버튼 글씨 |

### 관련 파일

| 파일 | 역할 |
|---|---|
| `frontend/src/assets/design-tokens.css` | `--sq-color-danger`, `--sq-color-danger-hover` 추가 |
| `frontend/src/views/ResourcesView.vue` | 내려받기 버튼 스타일을 danger 토큰으로 변경 |

---

## 5. 동작 원리

```
design-tokens.css (:root)
   --sq-color-danger: #DD3333
          │ var(--sq-color-danger)
          ▼
ResourcesView.vue .sq-resources__download
   background / border → danger
   :hover → danger-hover
```

### 왜 이렇게 했나

- **규칙 준수**: 컴포넌트에 hex 를 직접 쓰지 않고 토큰으로만 색을 지정한다.
- **재사용**: 이후 다른 강조 버튼(삭제·경고 등)도 같은 토큰을 쓰면 색이 통일된다.
- **일관성**: 실습 화면의 빨간 Submit 버튼과 같은 계열이라 "행동 버튼"으로 눈에 잘 띈다.

---

## 6. 난이도(단계) 대신 — 버튼 상태

| 상태 | 배경 | 글씨 |
|---|---|---|
| 기본 | danger | 흰색 |
| hover | danger-hover | 흰색 |

---

## 7. 핵심 정리

- 내려받기 버튼을 빨간색으로 바꾸고, 색은 새 토큰 `--sq-color-danger(-hover)` 로만 지정했다.

---

## 8. 검증

- 자료실 화면에서 8개 버튼 모두 빨간 배경·흰 글씨로 표시 확인
- 커밋: `e9d2915` (토큰), `ee4d02c` (화면)
