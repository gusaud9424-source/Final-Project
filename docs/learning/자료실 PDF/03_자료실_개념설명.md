# 03. 자료실 개념 설명 (브라우저에서 문서 만들기 · Blob 다운로드 · 이스케이프 · 디자인 토큰)

> 대상: 웹 개발을 처음 배우는 입문자
> 목표: "문서 내려받기" 버튼을 누르면 서버 없이 브라우저 안에서 문서 파일이 만들어져 저장되는 원리와, 그 과정에서 지키는 규칙을 코드와 함께 이해한다.
> 작성: 2026-10-06 · 오현명
> 함께 볼 문서: `01_자료실_학습문서_내려받기.md` · `02_내려받기버튼_색상변경.md` (작업 기록)

---

## 1. 요약

- 자료실 화면은 8개 과목을 난이도순(초급 → 중급 → 고급)으로 보여주고, 줄마다 **오른쪽 끝 빨간 "문서 내려받기" 버튼**이 있다.
- 버튼을 누르면 **브라우저가 직접** 학습 문서(HTML 파일)를 만들어 저장한다. 서버에 파일을 보관하거나 새 API 를 만들지 않았다.
- 문서 내용은 과목 상세 화면이 이미 쓰는 **콘텐츠 파일**(`courseGuides.js` 등)에서 가져온다. 콘텐츠를 고치면 화면과 문서에 함께 반영된다.
- 문서에 넣는 모든 글자는 **이스케이프**해서 HTML 코드로 해석되지 않게 했다.
- 문서 색은 직접 적지 않고 화면의 **디자인 토큰(`--sq-*`) 값을 읽어** 넣는다. 버튼 빨간색도 새 토큰 `--sq-color-danger` 로 지정했다.
- 내려받은 파일은 더블클릭하면 브라우저에서 문서처럼 열리고, 인쇄 메뉴로 PDF 저장도 된다.

## 2. 개념 설명 (비유)

### 2-1. 전체 그림: 도서관 즉석 인쇄기

```
 [버튼 클릭]
     │
     ▼
 buildResourceDoc(과목) ──── 콘텐츠 파일에서 장(章)별 글 모으기 (courseGuides · tierGuides · MISSION_GUIDE)
     │                      모든 글자 이스케이프
     │                      화면의 색 토큰 값 읽어 스타일에 넣기
     ▼
 HTML 문자열 (문서 한 장 전체)
     │
     ▼
 Blob 으로 포장 ──▶ 임시 주소(blob:...) ──▶ 보이지 않는 <a download> 클릭 ──▶ 파일 저장
                                                                      SecuQuest_<과목>_학습자료.html
```

- **책장(콘텐츠 파일)** 에 이미 정리된 글이 있고, **인쇄 버튼**을 누르면 그 자리에서 필요한 장을 골라 **소책자(HTML 파일)** 로 묶어 준다.
- 인쇄기가 도서관 안(브라우저)에 있어서 **본사(서버)에 주문할 필요가 없다.**

### 2-2. 왜 서버가 아니라 브라우저에서 만드나

| 방식 | 장점 | 단점 |
|---|---|---|
| 서버에서 PDF 를 만들어 보관 | 파일 형식 자유 | 파일 보관·갱신 관리, 새 API·라이브러리 필요 |
| **브라우저에서 HTML 을 즉석 생성 (선택)** | 서버 변경 없음, 콘텐츠 수정이 바로 반영 | 문서 깊이가 콘텐츠 파일 수준 |

## 3. 용어 설명

| 용어 | 쉬운 뜻 |
|---|---|
| HTML | 웹 문서를 만드는 언어. `<h2>` `<p>` 같은 태그로 제목·문단을 표시 |
| HTML 문자열 | HTML 문서 전체를 글자 하나의 긴 줄로 만든 것 |
| Blob | 브라우저 메모리 안에 만든 "파일 덩어리". 서버 없이 파일을 만들 때 사용 |
| MIME 타입 | 파일 종류 표시. 여기서는 `text/html;charset=utf-8` (한글이 깨지지 않게 UTF-8) |
| `URL.createObjectURL` | Blob 에 임시 주소(`blob:...`)를 붙여 주는 함수 |
| `URL.revokeObjectURL` | 다 쓴 임시 주소를 지워 메모리를 돌려주는 함수 |
| `<a download>` | 클릭하면 페이지 이동 대신 파일로 저장하게 하는 링크 |
| 이스케이프 | `<` `>` `&` `"` `'` 같은 특수문자를 `&lt;` 처럼 바꿔, 글자 그대로 보이게 하는 처리 |
| 엔티티 | 이스케이프된 표기 (`&lt;` = `<`, `&amp;` = `&`) |
| 디자인 토큰 | 색·간격 등 디자인 값을 이름 붙여 모아 둔 CSS 변수 (`--sq-color-accent` 등) |
| CSS 변수 | `--이름: 값` 으로 정의하고 `var(--이름)` 으로 쓰는 값 |
| `getComputedStyle` | 화면에 실제로 적용된 CSS 값을 읽어 오는 브라우저 함수 |
| 콘텐츠 파일 | 화면에 보여줄 글을 모아 둔 JS 파일 (`courseGuides.js`, `tierGuides.js`) |
| Pinia 스토어 | 여러 화면이 함께 쓰는 데이터 저장소 (`enroll` 스토어 = 8개 과목 목록) |
| `@media print` | 인쇄할 때만 적용되는 CSS 규칙 |

## 4. 구조와 코드

### 4-1. 자료실 화면

```vue
<!-- frontend/src/views/ResourcesView.vue (요약) -->
<li v-for="course in courses" :key="course.id">
  <span class="sq-badge">{{ course.difficulty }}</span>      <!-- 초급/중급/고급 배지 -->
  <p>{{ course.title }}</p>
  <button class="sq-resources__download" @click="downloadResourceDoc(course)">
    문서 내려받기
  </button>
</li>
```

- `courses` 는 `enroll` 스토어의 8개 과목 목록이다. 스토어에 이미 난이도순으로 정의돼 있어 정렬 코드가 필요 없다.

### 4-2. 문서 만들기: 글 모으기 + 이스케이프

```javascript
// frontend/src/utils/resourceDoc.js (요약)
function esc(text) {                         // 특수문자를 엔티티로 바꿈
  return String(text ?? "")
    .replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;").replace(/'/g, "&#39;");
}

function rich(text) {                        // 이스케이프 후, 백틱(`) 구간만 <code> 로 표시
  return esc(text).split("`").map((part, i) => (i % 2 ? `<code>${part}</code>` : part)).join("");
}
```

| 부분 | 의미 | 없으면 생기는 일 |
|---|---|---|
| `&` 를 가장 먼저 바꿈 | 이미 바꾼 `&lt;` 의 `&` 를 또 바꾸지 않게 순서를 지킴 | `&lt;` 가 `&amp;lt;` 로 이중 변환 |
| `<` `>` 변환 | 글 속 `<` 가 태그 시작으로 해석되지 않음 | 글자가 사라지거나 문서 구조가 깨짐 |
| 이스케이프 **후** `<code>` 추가 | 우리가 의도한 태그만 살아남음 | 콘텐츠 글이 마음대로 태그를 만들 수 있음 |

> 이스케이프는 SecuQuest 가 가르치는 **출력 인코딩** 원칙을 우리 코드에도 그대로 적용한 것이다. 문서에 들어가는 글은 "데이터"로만 다루고 "코드"로 해석되지 않게 한다.

### 4-3. 문서 구성 (7개 장)

| 장 | 내용 | 가져오는 곳 |
|---|---|---|
| 1. 한눈에 보기 | 취약점 정의 | `courseGuides` info.summary · `enroll` detail.summary |
| 2. 쉽게 이해하기 | 비유 | info.analogy |
| 3. 방어에 실패하면 | 피해 범위 | info.impact |
| 4. 어떻게 방어하나 | 방어 방법 · 핵심 원칙 | info.defense · detail.defense |
| 5. 실습 안내 | 목적 · 이유 · 화면 · 진행 방법 · 팁 | practice.* |
| 6. 레벨 구성 | 하 → 중 → 상 → 안전 | `tierGuides.js` (TIER_META) |
| 7. 미션 수행 가이드 | 1~3회차 | `MISSION_GUIDE` |

### 4-4. 색은 토큰 값을 읽어서

```javascript
function readTokens() {
  const style = getComputedStyle(document.documentElement);   // 화면 최상위(:root)의 실제 CSS 값
  const pick = (name) => style.getPropertyValue(name).trim();
  return { accent: pick("--sq-color-accent"), text: pick("--sq-text-main"), ... };
}
// 문서 <style> 에 ${t.accent} 처럼 넣음
```

- 내려받은 문서는 **앱 밖에서** 열리므로 `var(--sq-*)` 를 쓸 수 없다. 그래서 내려받는 순간의 토큰 값을 복사해 넣는다.
- 덕분에 코드에 색 값(hex)을 직접 적지 않는다는 프로젝트 규칙을 지키고, 토큰을 바꾸면 문서 색도 따라 바뀐다.

### 4-5. Blob 으로 파일 저장

```javascript
export function downloadResourceDoc(course) {
  const html = buildResourceDoc(course);
  const blob = new Blob([html], { type: "text/html;charset=utf-8" });   // ① 파일 덩어리
  const url = URL.createObjectURL(blob);                                 // ② 임시 주소
  const link = document.createElement("a");
  link.href = url;
  link.download = `SecuQuest_${course.id}_학습자료.html`;                // ③ 저장될 파일 이름
  document.body.appendChild(link);
  link.click();                                                          // ④ 보이지 않는 링크 클릭
  link.remove();
  URL.revokeObjectURL(url);                                              // ⑤ 임시 주소 정리
}
```

| 단계 | 의미 | 없으면 생기는 일 |
|---|---|---|
| ① `charset=utf-8` | 한글 인코딩 지정 | 한글이 깨져 보일 수 있음 |
| ③ `download` 속성 | 이동 대신 저장 | 새 탭으로 열리기만 하고 저장 안 됨 |
| ⑤ `revokeObjectURL` | 메모리 정리 | 여러 번 내려받으면 메모리가 쌓임 |

### 4-6. 빨간 버튼 = 새 토큰

```css
/* design-tokens.css */
--sq-color-danger: #DD3333;        /* 실습 화면 Submit 버튼과 같은 계열 */
--sq-color-danger-hover: #C42B2B;  /* 마우스를 올렸을 때 */

/* ResourcesView.vue */
.sq-resources__download       { background: var(--sq-color-danger); color: var(--sq-color-on-accent); }
.sq-resources__download:hover { background: var(--sq-color-danger-hover); }
```

- 색 값은 토큰 파일 한 곳에만 있고, 버튼은 토큰 이름만 쓴다.

## 5. 동작 흐름 예시

```
1. 헤더 [자료실] → 8개 과목 목록 (초급 4 · 중급 3 · 고급 1)
2. CSRF 줄의 [문서 내려받기] 클릭
3. 브라우저: 콘텐츠 7개 장 모으기 → 이스케이프 → 토큰 색 적용 → HTML 문자열 완성
4. Blob → 임시 주소 → SecuQuest_csrf_학습자료.html 저장 → 임시 주소 정리
5. 파일 더블클릭 → 브라우저에서 문서로 열림 → (선택) 인쇄 → PDF 로 저장
```

## 6. 주의점과 한계

- **문서 깊이 = 콘텐츠 파일 수준**이다. 더 자세한 설명을 원하면 `courseGuides.js` 를 보강하면 문서에도 자동 반영된다.
- 형식은 **HTML 파일**이다. PDF 가 필요하면 문서를 열어 인쇄 메뉴에서 "PDF 로 저장"을 쓴다.
- 자료실 폴더 이름은 "자료실 PDF" 지만 실제 산출물은 HTML 이다(사용자 요청으로 형식 변경).
- 참고 자료(`docs/resources-src`, 출판사 저작물 포함)는 문서에 쓰지 않았고 **저장소에 올리지 않는다.**

## 7. 핵심 정리

- 자료실 문서는 **브라우저에서 즉석 생성**한다: 콘텐츠 모으기 → 이스케이프 → 토큰 색 → Blob → `<a download>`.
- 모든 글자를 **이스케이프**해 문서 안 글이 코드로 해석되지 않게 했다.
- 색은 **디자인 토큰 값을 읽어** 넣어 hex 하드코딩 금지 규칙을 지켰다.
- 발표용 한 문장: **"자료실 문서는 서버 없이 브라우저가 기존 콘텐츠를 모아 즉석에서 HTML 파일로 만들고, 모든 글을 이스케이프해 안전하게 출력한다."**
