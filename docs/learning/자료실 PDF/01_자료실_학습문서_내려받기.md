# 01. 자료실 — 취약점별 학습 문서 내려받기

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 자료실에서 취약점별 학습 문서를 내려받는 흐름과, 문서가 만들어지는 원리를 이해한다.
> 작성: 2026-10-04 · 오현명
> 📘 개념 설명(용어·코드 의미·최종 구조)은 `03_자료실_개념설명.md` 참고.

---

## 1. 요약

- 비어 있던 **자료실** 화면에 8개 취약점 목록을 만들었다. 줄마다 **오른쪽 끝 "문서 내려받기" 버튼**이 있다.
- 버튼을 누르면 해당 취약점의 학습 문서가 **HTML 파일**로 내려받아진다. 더블클릭하면 브라우저에서 문서 형태로 열리고, 인쇄(PDF로 저장)도 된다.
- 문서 내용은 과목 상세에서 이미 쓰고 있는 콘텐츠를 모아 구성한다: 한눈에 보기 · 비유 · 방어 실패 시 피해 · 방어 방법 · 실습 안내 · 레벨 구성 · 미션 수행 가이드.
- 서버나 DB 변경은 없다. 문서는 브라우저에서 바로 만들어진다.

---

## 2. 개념 설명 (비유)

**도서관의 즉석 인쇄 서비스**와 같다.

- 책장(콘텐츠 파일)에 이미 정리된 내용이 있다.
- "인쇄" 버튼(문서 내려받기)을 누르면, 그 자리에서 필요한 장들을 골라 한 권의 소책자(HTML 문서)로 묶어 준다.
- 책장 내용을 고치면 다음에 인쇄하는 소책자에도 자동으로 반영된다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| Blob | 브라우저 메모리에 만든 파일 덩어리. 서버 없이 파일을 내려받게 할 때 사용 |
| 이스케이프 | `<` 같은 특수문자를 글자 그대로 보이게 바꾸는 처리. 문서에 들어가는 모든 텍스트에 적용 |
| 디자인 토큰 | `--sq-*` CSS 변수. 문서 색상은 하드코딩하지 않고 현재 토큰 값을 읽어 넣는다 |

---

## 4. 화면 & 동작

### 4-1. 자료실 화면

```
자료실
취약점별 학습 문서를 내려받아 읽어 보세요. ...
┌──────────────────────────────────────────────────────────┐
│ [초급] Command Injection                    [📄 문서 내려받기] │
│        입력값에 OS 명령을 주입해 ...                          │
│ [초급] XSS (Reflected)                      [📄 문서 내려받기] │
│ ...                                                      │
│ [고급] SQL Injection (Blind)                [📄 문서 내려받기] │
└──────────────────────────────────────────────────────────┘
```

- 순서는 난이도 순(초급 → 중급 → 고급)이다.

### 4-2. 내려받는 문서 구성

| 장 | 내용 | 출처(기존 콘텐츠) |
|---|---|---|
| 1. 한눈에 보기 | 취약점 정의와 발생 원인 | `courseGuides.js` info.summary · `enroll.js` detail.summary |
| 2. 쉽게 이해하기 | 비유 설명 | info.analogy |
| 3. 방어에 실패하면 | 피해 범위 | info.impact |
| 4. 어떻게 방어하나 | 방어 방법 + 핵심 원칙 | info.defense · detail.defense |
| 5. 실습 안내 | 실습 목적 · 왜 배우나 · 실습 화면 · 진행 방법 · 팁 | practice.* |
| 6. 레벨 구성 | 하 → 중 → 상 → 안전 학습 포인트 | `tierGuides.js` |
| 7. 미션 수행 가이드 | 1~3회차 미션 수행 방법 | `MISSION_GUIDE` |

- 파일 이름: `SecuQuest_<과목>_학습자료.html` (예: `SecuQuest_xss-stored_학습자료.html`)
- 문서 하단에 저작권·출처(DVWA 레벨 구조 참고) 문구가 들어간다.

### 관련 파일

| 파일 | 역할 |
|---|---|
| `frontend/src/views/ResourcesView.vue` | 자료실 화면(목록 + 오른쪽 끝 내려받기 버튼) |
| `frontend/src/utils/resourceDoc.js` | 학습 문서 HTML 생성 · 내려받기 |

---

## 5. 동작 원리

```
[문서 내려받기 클릭]
      ▼
buildResourceDoc(과목)
      - courseGuides · enroll 상세 · 레벨 안내 · 미션 안내에서 내용 수집
      - 모든 텍스트 이스케이프, 백틱(`) 구간만 <code> 로 표시
      - 현재 화면의 --sq-* 토큰 값을 읽어 문서 스타일에 넣음
      ▼
Blob(text/html) 생성 → <a download> 클릭 → 파일 저장
```

### 왜 이렇게 했나

- **콘텐츠 한 곳 관리**: 과목 상세와 자료실이 같은 콘텐츠 파일을 쓰므로, 설명을 고치면 두 곳에 함께 반영된다.
- **서버 부담 없음**: 문서를 브라우저에서 만들어 서버·DB 변경과 파일 보관이 필요 없다.
- **HTML 문서 형식**: 별도 프로그램 없이 브라우저로 바로 열리고, 필요하면 인쇄 메뉴에서 PDF로 저장할 수 있다.
- **안전한 문서**: 문서에 넣는 텍스트는 모두 이스케이프해 문서 자체에 스크립트가 섞이지 않게 했다.

---

## 6. 난이도(단계) 대신 — 문서 활용 순서

| 단계 | 문서에서 볼 곳 | 연결되는 미션 |
|---|---|---|
| 개념 이해 | 1~4장 | 1회차 개념 학습 |
| 실습 | 5~6장 (+ 실습 페이지 힌트) | 2회차 실습 성공 (하·중·상 통과) |
| 복습 | 3~4장 | 3회차 방어 퀴즈 (70% 이상) |

---

## 7. 핵심 정리

- 자료실에서 취약점마다 오른쪽 끝 버튼으로 학습 문서(HTML)를 내려받는다.
- 문서는 과목 상세의 기존 콘텐츠를 모아 7개 장으로 구성되며, 미션 수행 순서와 연결된다.
- 내용을 보강하려면 `courseGuides.js` 를 수정하면 문서에도 자동 반영된다.

---

## 8. 검증

- 자료실 화면: 8개 과목 목록 · 난이도 배지 · 오른쪽 끝 "문서 내려받기" 버튼 표시 확인
- XSS (Stored) 문서 생성 → 7개 장 렌더링 확인(브라우저 미리보기)
- **확인 필요**: 실제 버튼 클릭 후 파일 저장 · 더블클릭으로 열기 (브라우저 다운로드 동작은 직접 확인 권장)
- 참고: 문서 내용의 깊이는 현재 `courseGuides.js` 수준이다. DVWA 자료를 참고한 상세 설명은 이 파일에 보강하면 된다.
