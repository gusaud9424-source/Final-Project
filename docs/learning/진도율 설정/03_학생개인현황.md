# 03. 학생 개인 현황 페이지 (관리자)

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 관리자가 학생 한 명의 학습 기록을 한 화면에서 보는 페이지가 어떤 데이터로, 어떻게 그려지는지 이해한다.
> 작성: 2026-10-04 · 오현명

---

## 1. 요약

- 전체 학생 현황 표에서 **학생 이름을 누르면** 그 학생 전용 페이지(`/admin/students/<id>`)가 열린다.
- 상단에 **프로필**, 그 아래 **요약 카드 8개**를 같은 형식(라벨 · 아이콘 · 값 · 진행바 · 보조문구)으로 배치했다.
- 그래프는 **도넛 3개**(전체 진도 · 단계별 완료 · 포인트 획득 경로), **과목별 막대**, **주간 학습 활동 막대**, **출석 14칸 체크판**이다.
- 맨 아래에 **과목별 단계 완료 날짜 표**와 **최근 활동 10건**을 둬서 "언제 무엇을 했는지"까지 확인한다.
- 새 API `GET /api/v1/admin/students/<id>` 하나로 모든 데이터를 받고, 그래프는 외부 라이브러리 없이 SVG로 그린다.

---

## 2. 개념 설명 (비유)

병원의 **환자 차트 한 장**과 같다.

- 맨 위에는 이름 · 연락처 · 등록일 같은 **기본 정보**가 있다(프로필).
- 그 아래에는 체온 · 혈압 · 맥박처럼 **핵심 수치 카드**가 나란히 있다(요약 카드 8개).
- 수치 변화는 **그래프**로 보여준다(도넛 · 막대 · 주간 추이).
- 마지막으로 **진료 기록**을 날짜순으로 적는다(단계 완료 날짜 · 최근 활동).
- 의사(관리자)는 이 한 장만 보고 "요즘 상태가 어떤지, 어디서 막혔는지"를 판단한다.

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| 요약 카드 | 핵심 숫자 하나를 보여주는 카드. 모두 같은 틀(라벨·아이콘·값·진행바·보조문구) |
| 도넛 차트 | 가운데가 빈 원형 그래프. 전체 대비 비율을 보여준다 |
| SVG | 웹에서 도형을 코드로 그리는 형식. 확대해도 깨지지 않는다 |
| stroke-dasharray | SVG 원 테두리를 "그릴 길이 / 비울 길이"로 나눠 도넛 조각을 만드는 속성 |
| 학습한 날 | 단계 완료 · 포인트 · 경험치 기록이 있는 날짜 수(한국 시간 기준, 중복 제외) |
| 주간 학습 활동 | 최근 8주 동안 주(월요일 시작)별 완료 단계 수 |
| 미수령 보상 | 보물상자에 쌓여 있지만 아직 받지 않은 보상 건수 |
| 마스킹 | 휴대폰 번호 가운데 자리를 `****` 로 가리는 것 |

### 요약 카드 8개

| 카드 | 값 | 진행바 | 보조문구 |
|---|---|---|---|
| 전체 진도율 | 완료 단계 ÷ 전체 단계 | 진도율 | 단계 N/M 완료 |
| 보유 포인트 | 포인트 잔액 | - | 미수령 보상 N건 |
| 출석일 | 출석 N / 14일 | 출석 비율 | 출석 포인트 합계 |
| 완료 과목 | 3단계 모두 끝낸 과목 / 수강 과목 | 완료 비율 | 수강 · 전체 과목 수 |
| 레벨 · 경험치 | Lv.N | 다음 레벨까지 XP | 현재/필요 XP · 누적 XP |
| 실습 성공 | 실습 성공 과목 / 수강 과목 | 성공 비율 | - |
| 퀴즈 통과 | 퀴즈 통과 과목 / 수강 과목 | 통과 비율 | - |
| 학습한 날 | 활동한 날짜 수 | - | 마지막 활동(정체면 빨간 값) |

- 화면 폭이 좁아지면 4열 → 2열, 그래프 3열 → 2열 → 1열로 바뀐다.
- 색은 모두 `var(--sq-*)` 토큰만 사용했다(도넛 조각 색 포함).

## 5. 동작 원리

```
[1] 전체 학생 현황 표에서 학생 이름 클릭
      │  /admin/students/4 로 이동 (라우터: 관리자만 허용)
      ▼
[2] GET /api/v1/admin/students/4
      - 관리자 아님 403 · 없는 회원 404 · 관리자 계정 대상 400
      ▼
[3] 서버가 이 학생의 기록을 모아 계산
      - 과목·수강·task_progress  → 과목별 진도, 단계 완료 날짜, 완료 과목, 실습/퀴즈 수
      - point_ledger · xp_ledger → 포인트 잔액, 레벨, 획득 경로, 학습한 날
      - 출석판 로직(_board_state) 재사용 → 14칸 상태
      - rewards                 → 미수령 보상 수
      - 모든 기록을 시간순으로 합쳐 최근 활동 10건
      ▼
[4] 프런트: 요약 카드 8개 · 도넛 3개 · 막대 · 표 · 타임라인으로 렌더링
```

### 도넛 차트 원리

```
원 둘레 = 2πr
조각 길이 = (값 ÷ 전체) × 둘레
stroke-dasharray = "조각 길이  둘레"   → 조각만큼만 테두리를 그림
stroke-dashoffset = -(앞 조각 길이 합) → 다음 조각을 이어서 그림
rotate(-90)                         → 12시 방향에서 시작
```

### 왜 이렇게 설계했나

- **한 번의 요청**: 화면에 필요한 모든 데이터를 API 하나로 받는다. 카드마다 요청을 보내면 느리고 숫자끼리 시점이 어긋날 수 있다.
- **기존 로직 재사용**: 레벨(`compute_level`), 포인트 잔액(`points_balance`), 출석판(`_board_state`), 상태 판정(`_student_status`)을 그대로 써서 학생 화면 · 전체 현황과 숫자가 일치한다.
- **요약 카드 형식 통일**: 모든 카드를 같은 틀로 만들어 눈이 같은 위치에서 같은 종류의 정보를 찾게 했다. 카드 목록은 `statCards` 배열 하나로 관리해 항목 추가가 쉽다.
- **라이브러리 없는 SVG**: 차트 라이브러리를 추가하지 않고 도넛 · 막대를 직접 그려 의존성을 늘리지 않았다. 도넛은 `DonutChart.vue` 로 분리해 3곳에서 재사용한다.
- **미수강 과목도 표시**: 과목별 진도 막대에 8과목을 모두 보여주고 미수강은 "미수강"으로 표시해, 학생이 난이도 순서대로 진행하는지 바로 보이게 했다.
- **개인정보 최소 노출**: 휴대폰 번호는 마스킹해서 보여준다.

## 6. 난이도(단계) 대신 — 화면 구역별 역할

이 기능은 공격/방어 실습이 아니라 관리 화면이므로, "난이도" 대신 **화면 구역**으로 정리한다.

| 구역 | 답해 주는 질문 | 사용 데이터 |
|---|---|---|
| 프로필 | 누구인가, 지금 상태는? | users, 상태 판정 |
| 요약 카드 8개 | 얼마나 했나? | 진도 · 포인트 · 출석 · 경험치 |
| 진도 그래프 | 어떤 과목 · 단계에서 막혔나? | task_progress |
| 출석 · 주간 활동 | 꾸준히 하고 있나? | point_ledger(출석), task_progress |
| 포인트 획득 경로 | 무엇으로 보상을 받았나? | point_ledger(source별) |
| 단계 완료 날짜 · 최근 활동 | 언제 무엇을 했나? | 모든 기록 시간순 |

## 7. 핵심 정리

- 학생 이름을 누르면 **`/admin/students/<id>`** 개인 현황 페이지가 열린다.
- **요약 카드 8개**(전체 진도율 · 보유 포인트 · 출석일 · 완료 과목 · 레벨 · 실습 성공 · 퀴즈 통과 · 학습한 날)는 모두 같은 형식이다.
- **도넛 3개 · 막대 2종 · 출석판 · 표 · 타임라인**으로 한 페이지에서 학생의 학습 상태를 파악한다.
- 데이터는 API 하나로 받고, 계산은 기존 레벨 · 포인트 · 출석 · 상태 로직을 재사용한다.

## 8. 검증

- 백엔드 `admin.py` 문법 검사 통과
- API 확인(관리자 계정): demo1(id 4) → 200, 진도 47%(7/15) · 포인트 149P · 출석 1/14 · 미수령 보상 17건 · 학습한 날 2일
  - 없는 회원(99999) → 404, 관리자 계정(id 1) → 400
- 브라우저 확인:
  - 1440px 폭에서 프로필 · 요약 카드 8개 · 그래프 6개 · 표 · 최근 활동이 **한 화면**에 배치
  - 800px 폭에서 2열로 바뀌는 반응형 확인
  - 전체 학생 현황 표의 이름 링크(`/admin/students/4`, `/admin/students/2`) 클릭 시 해당 학생 페이지로 이동
- 참고: 주간 학습 활동 · 최근 활동은 **수강취소한 과목의 기록도 포함**한다(진도 보존 정책). 요약 카드와 진도 그래프는 수강 중인 과목만 계산한다.
