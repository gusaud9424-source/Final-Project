# 05. 레벨업 보상 (경험치 / 포인트 랜덤)

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 레벨이 오를 때 보상이 지급되는 조건과, 중복 없이 한 번만 지급되는 원리를 이해한다.
> 작성: 2026-10-05 · 오현명
> 📘 개념 설명(용어·코드 의미·최종 구조)은 `09_보상구조_개념설명.md` 참고.

---

## 1. 요약

- **레벨이 오를 때마다 보상 1개**를 **보물상자**로 지급한다.
- 보상 종류는 **경험치 또는 포인트 중 랜덤**이다.
- **레벨이 높을수록 보상 금액이 커진다.**
- 같은 레벨 보상은 **한 번만** 받는다. 레벨업 보상으로 받은 경험치로 다시 레벨이 오르면 그 레벨 보상도 이어서 지급된다.
- 이미 레벨이 올라 있는 계정은 지나온 레벨(2레벨부터)의 보상이 보물상자에 한꺼번에 들어온다.

---

## 2. 개념 설명 (비유)

**계단 층마다 있는 기념품 자판기**와 같다.

- 새 층(레벨)에 올라서면 그 층 자판기에서 기념품이 한 번 나온다. 무엇이 나올지(경험치/포인트)는 랜덤이다.
- 위층일수록 기념품이 크다. 이미 받은 층의 자판기는 다시 눌러도 나오지 않는다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| 레벨 | 누적 경험치로 계산. L → L+1 에 필요한 경험치 = L × 100 (최대 50레벨) |
| `levelup` | 레벨업 보상의 source |
| ref `levelup:<레벨>` | 레벨별 중복 지급 방지 키 (예: `levelup:3`) |
| 멱등 | 여러 번 확인해도 같은 레벨 보상이 두 번 생기지 않음 |

---

## 4. 화면 & 동작

### 4-1. 레벨별 보상 범위

| 레벨 | 경험치일 때 | 포인트일 때 |
|---|---|---|
| 2 | 50 ~ 80 | 20 ~ 36 |
| 3 | 65 ~ 100 | 25 ~ 44 |
| 5 | 95 ~ 140 | 35 ~ 60 |
| 10 | 170 ~ 240 | 60 ~ 100 |
| 공식 | (20 + 레벨×15) ~ (40 + 레벨×20) | (10 + 레벨×5) ~ (20 + 레벨×8) |

### 4-2. 보물상자 표시 예

```
보물상자
🎁 레벨 3 달성        포인트 +31
🎁 레벨 2 달성        경험치 +64
```

### 관련 파일

| 파일 | 역할 |
|---|---|
| `backend/app/rewards.py` | `levelup_range`, `ensure_levelup_rewards`, `_balance_after_claim` 추가 · 보물상자 목록 조회 시 레벨업 보상 확인 |
| `backend/app/courses.py` | 미션 탭 수령 후 레벨업 보상 확인 |
| `backend/app/admin.py` | 관리자 보상 내역 라벨 "레벨업" |

## 5. 동작 원리

```
[경험치 보상 수령]  보물상자 / 미션 탭에서 클릭
      ▼  원장(xp_ledger)에 경험치 기록 → 누적 경험치 증가
[ensure_levelup_rewards]  (수령 직후 · 보물상자 목록 조회 시)
      - 현재 레벨 계산
      - 2레벨 ~ 현재 레벨 중 levelup:<레벨> 보상이 없는 레벨만
          → 종류 랜덤(경험치/포인트), 레벨 공식으로 금액 결정 → 미수령 생성
      ▼
[보물상자]  "레벨 N 달성" 보상 표시 → 클릭 수령
      - 경험치 보상이면 다시 레벨이 오를 수 있음 → 다음 확인 때 그 레벨 보상 생성
```

### 왜 이렇게 했나

- **한 곳에서 확인**: 경험치는 모두 보상 수령(`_apply_claim`)으로만 들어오므로, 수령 직후와 보물상자 조회 때 확인하면 레벨업을 놓치지 않는다.
- **중복 방지**: 레벨마다 고유 ref 를 쓰고, 사용자 행을 잠근 상태에서 기존 보상·원장을 확인한 뒤 생성한다.
- **랜덤 + 성장 보상**: 종류는 랜덤으로 재미를 주고, 금액은 레벨에 비례해 높은 레벨까지 동기를 유지한다.
- **보물상자 수령**: 미션 외 보상은 모두 보물상자에서 받는 기존 규칙을 따른다.

---

## 6. 난이도(단계) 대신 — 레벨업 흐름 예

| 상황 | 누적 경험치 | 레벨 | 생성되는 보상 |
|---|---|---|---|
| 경험치 120 수령 | 120 | 2 | 레벨 2 달성 (랜덤) |
| 레벨 2 보상으로 경험치 +70 수령 | 190 | 2 | 없음 |
| 경험치 120 추가 수령 | 310 | 3 | 레벨 3 달성 (랜덤) |

---

## 7. 핵심 정리

- 레벨이 오를 때마다 보물상자로 **경험치 또는 포인트(랜덤)** 보상 1개를 지급하며, **높은 레벨일수록 금액이 크다.**
- 같은 레벨 보상은 한 번만 생성되고, 이미 지난 레벨 보상도 보정된다.

---

## 8. 검증

- 백엔드 `rewards.py` · `courses.py` · `admin.py` 문법 검사 통과
- 보물상자 목록 API 정상 응답 확인(비로그인 401 처리 유지)
- **확인 필요**: 로그인 후 보물상자를 열어 "레벨 N 달성" 보상이 표시되는지, 경험치 수령으로 레벨이 오르면 새 레벨 보상이 추가되는지 (이 세션은 로그아웃 상태라 직접 확인하지 못함)
