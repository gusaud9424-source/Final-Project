# 04. 미션 탭 1~3회차 보상 수령 통일

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 미션 탭의 세 미션이 모두 같은 방식(오른쪽 칸 클릭 → 보상 1개)으로 수령되는 구조를 이해한다.
> 작성: 2026-10-04 · 오현명
> 📘 개념 설명(용어·코드 의미·최종 구조)은 `09_보상구조_개념설명.md` 참고.

---

## 1. 요약

- **변경**: 2회차 "실습 성공" 보상을 보물상자 안내에서 **미션 탭 오른쪽 칸 클릭 수령**으로 되돌렸다.
- 이제 **1회차 개념 학습 · 2회차 실습 성공 · 3회차 방어 퀴즈 모두** 미션을 완수하면 오른쪽 칸에 **보상 1개**가 표시되고, 클릭하면 받는다.
- **보물상자**에는 실습 페이지의 **레벨별 클리어 보상**(하·중·상·안전)과 출석 등 미션 외 보상만 들어간다.
- 2회차 완료 조건은 그대로 **하·중·상 3개 레벨 모두 통과**다.

---

## 2. 개념 설명 (비유)

**도장판과 계단 선물**이 따로 있는 것과 같다.

- 도장판(미션 탭) = 과제 3칸. 칸마다 과제를 끝내면 도장(보상) 1개를 그 자리에서 받는다.
- 계단 선물(레벨 클리어 보상) = 실습 계단을 오를 때마다 택배 보관함(보물상자)으로 온다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| `COURSE_REWARD_SOURCES` | 미션 탭에서만 받는 보상 종류. `("concept", "practice", "mission")` |
| `practice` | 2회차 실습 성공 미션 보상 (ref `practice:<과목>`, 과목당 1개) |
| `practice_<레벨>` | 실습 페이지 레벨별 클리어 보상 (보물상자) |

| 회차 | 미션 | 완수 조건 | 보상 | 받는 곳 |
|---|---|---|---|---|
| 1회차 | 개념 학습 | 과목 정보 학습 완료 | 1개 | 미션 탭 오른쪽 칸 클릭 |
| 2회차 | 실습 성공 | 하·중·상 모두 통과 | 1개 | 미션 탭 오른쪽 칸 클릭 |
| 3회차 | 방어 퀴즈 | 퀴즈 70% 이상 | 1개 | 미션 탭 오른쪽 칸 클릭 |

## 5. 동작 원리

```
[실습 페이지에서 상 레벨까지 통과]
      - 레벨별 클리어 보상 → 보물상자 (레벨마다)
      - 하·중·상 모두 통과 → 2회차 실습 성공 완료 + 미션 보상 1개 생성(미수령)
      ▼
[미션 탭 열기]  GET /courses/<slug>/rewards
      - 완수한 미션 중 보상이 없으면 1개 생성(보정, 멱등)
      - 완수한 칸: "보상 받기" / 완수 전: "미션 완료 시 지급"
      ▼
[칸 클릭]  POST /courses/<slug>/rewards/<미션>/claim → 원장 반영
```

### 왜 이렇게 했나

- **세 미션의 규칙 통일**: 같은 미션 목록 안에서 한 칸만 받는 곳이 다르면 헷갈린다. 1~3회차 모두 "완수 → 오른쪽 칸 클릭 → 1개 수령"으로 맞췄다.
- **역할 분리**: 미션 탭은 과목 학습 단계 보상, 보물상자는 실습 레벨·출석 같은 활동 보상으로 나눴다.
- **한 보상은 한 곳에서만**: `COURSE_REWARD_SOURCES` 로 서버가 수령 위치를 강제해 중복 수령을 막는다.

## 6. 난이도(단계) 대신 — 미션 칸 상태

| 상태 | 표시 | 클릭 |
|---|---|---|
| 미완수 | 미션 완료 시 지급 (범위) | 불가 |
| 완수 · 미수령 | 받을 수 있어요! 보상 받기 | 가능 |
| 수령 완료 | 수령 완료 | 불가 |

---

## 7. 핵심 정리

- 미션 탭 1~3회차 모두 **완수 후 오른쪽 칸 클릭으로 보상 1개**를 받는다.
- 실습 페이지 **레벨별 클리어 보상**은 그대로 **보물상자**에서 받는다.

---

## 8. 검증

- 백엔드 `rewards.py` · `courses.py` 문법 검사 통과
- `GET /courses/sql-injection/rewards`: 2회차 practice `pending / claimAt: mission` (포인트 +39) → 미션 탭에서 수령 가능 확인
- `GET /rewards/pending`: 보물상자에는 레벨 보상("Command Injection 실습 하 레벨")만 남은 것 확인
- **확인 필요**: 미션 탭에서 2회차 보상 클릭 수령 후 보유 포인트 증가
