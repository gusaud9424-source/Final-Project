# 03. 실습 레벨별 클리어 보상 (하 · 중 · 상 · 안전)

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 실습 보상이 레벨마다 따로 지급되는 구조와, 중복 지급을 막는 원리를 이해한다.
> 작성: 2026-10-04 · 오현명
> 📘 개념 설명(용어·코드 의미·최종 구조)은 `09_보상구조_개념설명.md` 참고.

---

## 1. 요약

- **변경**: "하·중·상을 모두 통과해야 보상 1회" → **하 · 중 · 상 · 안전 각 레벨을 클리어할 때마다 보상 지급**.
- 보상은 모두 **헤더 보물상자**에서 받는다. 미션 탭 "실습 성공" 칸은 레벨 보상 현황을 "보물상자에서 받기"로 안내만 한다.
- **높은 레벨일수록 보상이 크다**(하 < 중 < 상). 안전 레벨은 방어 확인 단계라 하 레벨 수준으로 지급한다.
- 같은 레벨은 **한 번만** 지급된다(다시 성공해도 추가 보상 없음).
- 레벨별 보상 도입 전에 이미 통과한 레벨도 실습 페이지를 열면 보상이 보물상자로 들어온다.
- 미션 탭 2회차 "실습 성공" 완료 조건(하·중·상 모두 통과)은 그대로다.

---

## 2. 개념 설명 (비유)

**계단마다 놓인 선물 상자**와 같다.

- 한 계단(레벨)을 오를 때마다 그 계단의 선물이 택배 보관함(보물상자)으로 온다.
- 위 계단일수록 선물이 크다. 같은 계단을 다시 밟아도 선물은 한 번뿐이다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| `practice_<레벨>` | 레벨별 클리어 보상의 source (`practice_low` · `practice_medium` · `practice_high` · `practice_impossible`) |
| ref | 중복 방지 키. `practice:<과목>:<레벨>` (예: `practice:command-injection:low`) |
| 클리어 | 하·중·상은 공격 성공, 안전은 1회 이상 시도해 방어 확인 |

## 4. 화면 & 동작

### 4-1. 레벨별 보상 범위

| 레벨 | 경험치(초급 과목) | 포인트(중급·고급 과목) |
|---|---|---|
| 하 | 20 ~ 40 | 10 ~ 20 |
| 중 | 40 ~ 70 | 20 ~ 35 |
| 상 | 70 ~ 110 | 35 ~ 55 |
| 안전 | 20 ~ 40 | 10 ~ 20 |

### 4-2. 실습 페이지 결과 문구

| 상황 | 문구 |
|---|---|
| 레벨 첫 클리어 | "하 레벨 클리어 보상: 경험치 +N — 헤더의 보물상자에서 받으세요" |
| 이미 보상을 받은 레벨 재성공 | "이미 이 레벨의 클리어 보상을 받았습니다." |

### 4-3. 보물상자 목록 예

```
보물상자
🎁 Command Injection 실습 하 레벨   경험치 +30
🎁 Command Injection 실습 중 레벨   경험치 +55
...
```

## 5. 동작 원리

```
[레벨에서 실행]  POST /courses/<slug>/practice/run
      - 잠금 검사 → 실행 → 클리어 판정
      - 클리어 시 roll_pending(source="practice_<레벨>", ref="practice:<과목>:<레벨>")
          · 같은 ref 가 이미 있으면 생성하지 않음 (레벨당 1회)
      - 하·중·상 모두 통과 시 실습 미션(2회차) 완료
      ▼
[헤더 보물상자]  GET /rewards/pending → 레벨 보상 표시 → 클릭 수령(원장 반영)

[실습 페이지 열기]  GET /courses/<slug>/practice/tiers
      - 이미 통과한 레벨 중 보상이 없는 레벨은 보상 생성(보정, 멱등)
```

### 왜 이렇게 했나

- **단계마다 즉시 보상**: 레벨 하나를 넘을 때마다 보상을 받아 다음 레벨로 갈 동기가 생긴다.
- **난이도에 비례한 보상**: 어려운 레벨일수록 많이 줘서 하 → 중 → 상 학습 흐름을 강화한다.
- **중복 방지는 ref 하나로**: 레벨마다 다른 ref 를 써서, 기존 중복 방지 로직(`roll_pending` + UNIQUE 제약)을 그대로 활용했다.
- **기존 기록 유지**: 레벨 구조 이전의 과목당 1회 실습 보상(`practice:<과목>`)은 지우지 않고 미션 탭에 함께 표시한다.

---

## 6. 난이도(단계) 대신 — 레벨별 보상 흐름

| 통과 레벨 | 지급되는 보상 | 실습 미션(2회차) |
|---|---|---|
| 하 | 하 레벨 보상 | 미완료 |
| + 중 | 중 레벨 보상 | 미완료 |
| + 상 | 상 레벨 보상 | **완료** |
| + 안전 | 안전 레벨 보상 | 완료 |

---

## 7. 핵심 정리

- 실습 보상은 **레벨을 클리어할 때마다** 지급되고, 모두 **보물상자**에서 받는다.
- 높은 레벨일수록 보상이 크며, 같은 레벨 보상은 한 번만 받는다.
- 미션 탭은 개념 학습·방어 퀴즈만 직접 수령, 실습 칸은 보물상자 안내다.

---

## 8. 검증

- 백엔드 `rewards.py` · `courses.py` · `admin.py` 문법 검사 통과
- Command Injection(하 통과 상태)에서 실습 레벨 조회 시 보물상자에 "Command Injection 실습 하 레벨 경험치 +30" 생성 확인
- 미션 탭 실습 칸: `claimAt: "chest"` 로 레벨 보상 현황 표시 확인
- **확인 필요**: 중·상·안전 레벨 클리어 시 각 레벨 보상이 보물상자에 추가되는지 실습으로 직접 확인
