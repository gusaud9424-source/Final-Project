# 07. 수강신청 시 진도 초기화 · 미완수 미션 보상 표시 정리

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 수강신청하면 진도가 0%에서 시작하는 이유와, 미션을 완수해야만 보상이 표시되는 구조를 이해한다.
> 작성: 2026-10-05 · 오현명

---

## 1. 요약

- **문제 1**: 수강신청만 했는데 진도율이 33~67%로 표시됐다.
- **문제 2**: 3회차 방어 퀴즈를 풀지 않았는데 "수령 완료"로 표시됐다.
- **원인**: 수강취소 시 진도를 "재수강 때 이어서 하도록" 보존하는 설계였다. 그래서 예전 테스트(10월 2~3일) 때 남은 완료 기록과 보상 기록이 재수강 후에도 그대로 보였다.
- **조치 1**: **수강신청하면 그 과목의 진도를 초기화**해 0%에서 시작한다(미션·레벨 기록 삭제, 받지 않은 과목 보상 삭제).
- **조치 2**: 미션 탭은 **미션을 완수하지 않으면** 예전에 받은 기록이 있어도 "미션 완료 시 지급"으로 표시한다.
- 이미 받은 보상(원장)은 남겨 두어, 다시 완수해도 **같은 보상이 두 번 지급되지 않는다**(완수 후 "수령 완료" 표시).

---

## 2. 개념 설명 (비유)

**재수강하면 새 출석부를 받는 것**과 같다.

- 수업을 취소했다가 다시 신청하면 출석부·과제 체크표가 새것으로 바뀐다(0%).
- 다만 예전에 받은 장학금(이미 받은 보상)은 다시 주지 않는다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| `_reset_course_progress` | 수강신청 시 해당 과목의 진도·레벨 기록과 미수령 과목 보상을 지우는 함수 |
| 미수령 보상 | 생성됐지만 아직 받지 않은 보상 (초기화 대상) |
| 원장(ledger) | 실제로 받은 경험치·포인트 기록 (초기화하지 않음) |

---

## 4. 화면 & 동작

| 상황 | 변경 전 | 변경 후 |
|---|---|---|
| 수강취소 → 수강신청 | 예전 진도(33~67%) 그대로 | **0%** |
| 3회차 퀴즈 미통과 | 예전 기록으로 "수령 완료" | "미션 완료 시 지급" |
| 3회차 퀴즈 다시 통과 | — | 완료 · "수령 완료"(이미 받은 보상은 재지급 없음) |
| 처음 받는 미션 | — | 완수 시 "보상 받기" → 클릭 수령 |

### 관련 파일

| 파일 | 역할 |
|---|---|
| `backend/app/enrollments.py` | 수강신청 시 `_reset_course_progress` 실행 |
| `backend/app/courses.py` | 미완수 미션은 항상 "미션 완료 시 지급"(`_locked_state`) 표시 |

---

## 5. 동작 원리

```
[수강신청]  POST /enrollments
      - _reset_course_progress(사용자, 과목)
          · task_progress (concept·practice·defense·tier_*) 삭제
          · 이 과목 미수령 보상(concept/practice/mission/레벨 보상) 삭제
      - 수강 정보 생성 → 진도 0%

[미션 탭]  GET /courses/<slug>/rewards
      - 완수하지 않은 미션 → 미션 완료 시 지급
      - 완수한 미션 → 보상 받기 / 수령 완료
```

### 왜 이렇게 했나

- **정확한 진도**: 수강신청 직후 학생이 아무것도 하지 않았는데 진도가 올라가 있으면 학습 현황을 믿을 수 없다.
- **보상은 성공 조건으로만**: 미션 보상은 그 수강에서 실제로 완수했을 때만 표시·수령된다.
- **중복 지급 방지**: 이미 받은 보상 기록은 지우지 않아, 취소·재신청을 반복해 보상을 계속 받는 것을 막는다.

---

## 6. 난이도(단계) 대신 — 초기화 대상

| 데이터 | 수강신청 시 |
|---|---|
| 미션 완료 기록 (개념·실습·퀴즈) | 삭제 |
| 레벨 통과 기록 (하·중·상·안전) | 삭제 |
| 이 과목의 미수령 보상 | 삭제 |
| 이미 받은 보상(원장) · 레벨 · 포인트 | 유지 |

---

## 7. 핵심 정리

- 수강신청하면 과목 진도가 0%에서 시작한다.
- 미션 보상은 이번 수강에서 실제로 완수해야만 표시·수령된다.
- 이미 받은 보상은 다시 지급되지 않는다.

---

## 8. 검증

- 백엔드 전체 문법 검사 통과
- **확인 필요**: 이미 수강 중인 과목은 예전 기록이 남아 있으므로 **수강취소 → 수강신청**을 한 번 하면 0%로 초기화된다. 이후 미션 탭이 모두 "미션 완료 시 지급"인지 확인
