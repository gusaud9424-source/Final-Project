# 08. 1회차 개념 학습 — 확인 문제 (5문제 중 3문제 이상)

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 개념 학습 미션이 "탭 열람"이 아니라 "확인 문제 통과"로 완료되는 구조를 이해한다.
> 작성: 2026-10-05 · 오현명

---

## 1. 요약

- **변경 전**: 과목 정보 탭을 클릭만 해도 1회차(개념 학습)가 완료됐다.
- **변경 후**: 과목 정보 탭 하단의 **개념 확인 문제 5개**를 풀어 **3개 이상** 맞혀야 1회차가 완료된다.
- 완료되면 미션 탭 1회차 오른쪽 칸에 보상이 표시되고, **클릭해야 받는다**(자동 수령 없음).
- 문제는 3회차 50문항 퀴즈와 **별도 파일**(`backend/app/concept_check.py`)에서 관리한다. 과목별로 5문항 이상 등록되면 매번 5개를 무작위로 낸다. 5문항 미만인 과목은 "준비 중"으로 표시된다.
- 1회차 완료는 **확인 문제 통과 기록(`concept_check`)이 있을 때만** 인정한다. 예전 방식(탭 열람)으로 생긴 완료 기록은 무시된다.
- 탭 열람만으로 완료시키던 API(`POST /tasks/concept`)는 막았다.

---

## 2. 개념 설명 (비유)

**수업 후 쪽지 시험**과 같다.

- 교과서를 펼친 것만으로는 출석 도장을 주지 않는다.
- 5문제 쪽지 시험에서 3문제 이상 맞혀야 "이 단원 이해 완료" 도장(1회차 완료)을 준다.
- 틀리면 교과서를 다시 읽고 새 문제로 재도전한다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| 개념 확인 문제 | 과목 정보 내용을 이해했는지 확인하는 5문항 객관식 |
| 문항 풀(pool) | 과목별로 골라 둔 개념 문항 5~6개. 여기서 5개를 무작위 출제 |
| 세션 출제 기록 | 서버가 낸 문항 id 를 세션에 저장해, 그 문항으로만 한 번 채점 |

## 4. 화면 & 동작

### 4-1. 과목 정보 탭 하단

```
┌ ❓ 개념 확인 문제 ─────────────────────────────┐
│ 위 과목 정보를 읽고 5문제를 풀어 보세요.         │
│ 3문제 이상 맞히면 미션 1회차가 완료됩니다.        │
│ [ 문제 풀기 ]                                   │
│  1. ...  ○ ① ○ ② ○ ③ ○ ④                     │
│  ...                                           │
│ [ 제출하기 (5/5) ]                              │
│ → 4 / 5 정답 · 통과! 미션 탭에서 보상을 받으세요  │
│   (각 문항 정답·해설 표시, 실패 시 [다시 풀기])    │
└────────────────────────────────────────────────┘
```

### 4-2. 미션 탭 1회차

| 상태 | 표시 |
|---|---|
| 확인 문제 미통과 | 미완료 · 미션 완료 시 지급 |
| 통과 · 미수령 | 완료 · 받을 수 있어요! 보상 받기 (클릭 수령) |
| 수령 후 | 완료 · 수령 완료 |

### 관련 파일

| 파일 | 역할 |
|---|---|
| `backend/app/concept_check.py` | 과목별 개념 확인 문항 (형식만 정의, 문항은 추후 작성) |
| `backend/app/courses.py` | `GET /concept-check`(출제), `POST /concept-check/submit`(채점·완료), `POST /tasks/concept` 차단 |
| `backend/app/progress.py` | `concept_check` 통과 기록이 있어야 1회차 완료로 인정 |
| `frontend/src/components/practice/ConceptCheck.vue` | 확인 문제 UI (신규) |
| `frontend/src/views/CourseDetailView.vue` | 과목 정보 탭 하단에 확인 문제 배치, 탭 클릭 시 자동 완료 제거 |
| `frontend/src/content/courseGuides.js` | 1회차 미션 설명 변경 |

## 5. 동작 원리

```
[문제 풀기]  GET /courses/<slug>/concept-check
      - 과목 문항 풀에서 5개 무작위 선택
      - 문항 id 를 세션에 저장, 정답은 내려주지 않음
      ▼
[제출하기]  POST /courses/<slug>/concept-check/submit { answers }
      - 세션에 저장된 문항만 채점 (출제 기록은 채점 후 삭제 → 같은 문제로 재제출 불가)
      - 3개 이상 정답 → 1회차 완료 + 개념 학습 보상 미수령 생성
      - 응답: 점수, 문항별 정답·해설
      ▼
[미션 탭]  1회차 "보상 받기" 클릭 → 수령
```

### 왜 이렇게 했나

- **실제 이해 확인**: 탭을 여는 것만으로는 읽었는지 알 수 없다. 짧은 확인 문제로 학습 여부를 검증한다.
- **기존 문항 재사용**: 팀이 만든 퀴즈 은행에서 개념 문항만 골라, 내용 일관성을 지키고 중복 작성을 줄였다.
- **부정 방지**: 정답을 클라이언트에 보내지 않고, 서버가 출제한 문항으로만 한 번 채점한다.
- **보상은 클릭 수령**: 다른 미션과 같이 미션 탭에서 직접 눌러 받는다.

---

## 6. 난이도(단계) 대신 — 1회차 진행 순서

| 단계 | 행동 |
|---|---|
| 1 | 과목 정보 탭에서 설명 읽기 |
| 2 | 개념 확인 문제 5개 풀기 |
| 3 | 3개 이상 정답 → 1회차 완료 (실패 시 새 문제로 재도전) |
| 4 | 미션 탭에서 보상 받기 클릭 |

---

## 7. 핵심 정리

- 1회차는 과목 정보 탭의 **확인 문제 5개 중 3개 이상 정답**으로만 완료된다.
- 보상은 미션 탭에서 **클릭해서** 받는다.

---

## 8. 검증

- 백엔드 문법 검사 통과
- 현재 문항이 비어 있어 "문제 풀기"를 누르면 **"개념 확인 문제를 준비 중입니다."** 안내가 표시된다(오류가 아닌 안내 문구).
- **남은 작업**: `concept_check.py` 에 과목별 문항 5개 이상 작성 → 저장하면 바로 출제된다.
- 프런트 `ConceptCheck.vue` · `CourseDetailView.vue` 모듈 로드 확인
- **확인 필요**: 로그인 후 과목 정보 탭에서 문제 풀기 → 3개 미만 실패 / 3개 이상 통과 → 미션 탭 1회차 "보상 받기" 표시 및 클릭 수령
