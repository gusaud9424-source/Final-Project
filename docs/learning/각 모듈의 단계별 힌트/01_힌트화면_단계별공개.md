# 01. 힌트 화면 개선 — 한 번에 하나씩 펼치기

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: 실습 힌트를 한꺼번에 보여주지 않고 단계별로 하나씩 펼치게 바꾼 이유와 동작을 이해한다.
> 작성: 2026-10-06 · 오현명

---

## 1. 요약

- **변경 전**: "힌트 보기"를 누르면 그 레벨의 힌트가 **전부 한꺼번에** 목록으로 나왔다. 마지막 힌트에 정답에 가까운 예시가 있어 바로 보게 되는 문제가 있었다.
- **변경 후**: 힌트를 **1개씩** 보여주고, "다음 힌트 보기 (2/3)" 버튼을 눌러야 다음 힌트가 열린다.
- 상단에 **"하 레벨 힌트 · 1 / 3"** 과 진행 막대를 보여줘 지금 몇 번째 힌트인지 알 수 있다.
- 레벨을 바꾸거나 힌트를 다시 열면 **1번 힌트부터** 다시 시작한다.
- 힌트 **문구는 바꾸지 않았다**(서버의 기존 힌트 그대로). 화면 표시 방식만 바꿨다.

---

## 2. 개념 설명 (비유)

**퀴즈 프로그램의 힌트 카드**와 같다.

- 진행자가 힌트 카드를 한 장씩 넘긴다. 첫 장만 보고 맞히면 가장 좋고, 모르면 다음 장을 넘긴다.
- 카드를 한 번에 다 펼치면 생각할 틈 없이 마지막 카드(정답에 가까운 힌트)를 보게 된다.
- 그래서 "스스로 생각 → 필요할 때만 다음 힌트" 순서로 학습하게 만든 것이다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| 단계별 힌트 | 레벨마다 서버가 주는 힌트 목록 (보통 2~3개, 앞쪽일수록 방향만, 뒤쪽일수록 구체적) |
| `revealedCount` | 지금까지 펼친 힌트 개수 (처음 1) |
| 점진적 공개 | 정보를 한 번에 다 주지 않고 필요할 때 조금씩 보여주는 방식 |
| 잠긴 레벨 힌트 | 아직 열리지 않은 레벨의 힌트는 서버가 403 으로 주지 않는다 (`난이도 학습 구조` 참고) |

---

## 4. 화면 & 동작

```
┌ 💡 하 레벨 힌트                                  1 / 3 ┐
│ ███████████░░░░░░░░░░░░░░░░░░░░░░                      │  ← 진행 막대
│ ┌ [힌트 1] ─────────────────────────────────────────┐  │
│ │ (첫 번째 힌트 문구)                                 │  │
│ └───────────────────────────────────────────────────┘  │
│ [ 다음 힌트 보기 (2/3) ]                                │
└────────────────────────────────────────────────────────┘
          ↓ 끝까지 펼치면
  "모든 힌트를 확인했습니다. 직접 시도해 보세요!"
```

| 상황 | 동작 |
|---|---|
| "힌트 보기" 클릭 | 힌트 1개만 표시 |
| "다음 힌트 보기" 클릭 | 다음 힌트 1개 추가 |
| 모두 펼침 | 버튼 대신 완료 문구 |
| 레벨 변경 / 힌트 다시 열기 | 1번 힌트부터 다시 |
| 힌트 없는 레벨 | "이 레벨에는 힌트가 없습니다." |

### 관련 파일

| 파일 | 역할 |
|---|---|
| `frontend/src/views/ChapterDetailView.vue` | 단계별 힌트 표시(`revealedCount`), 진행 막대, 다음 힌트 버튼, 스타일 |

---

## 5. 동작 원리

```javascript
const revealedCount = ref(1);              // 펼친 힌트 개수

hints.slice(0, revealedCount)              // 앞에서부터 펼친 개수만 그림
@click="revealedCount++"                   // 다음 힌트 보기
toggleHints / selectTier → revealedCount = 1   // 다시 열거나 레벨을 바꾸면 처음부터
```

### 왜 이렇게 했나

- **스스로 생각할 시간**: 힌트를 한꺼번에 보면 학습이 아니라 따라 하기가 된다.
- **서버 변경 없음**: 힌트 문구와 API(`GET /practice/hints`)는 그대로 두고 화면만 바꿨다. 잠긴 레벨 힌트를 서버가 막는 규칙도 그대로다.
- **진행 표시**: "1 / 3"과 막대로 남은 힌트 수를 알려 줘, 몇 번 더 볼 수 있는지 예측할 수 있다.
- 색은 모두 `var(--sq-*)` 토큰만 사용했다.

---

## 6. 핵심 정리

- 힌트를 **한 번에 하나씩** 펼치고, 진행 상황(1/3)을 보여준다.
- 레벨을 바꾸면 처음부터, 힌트 문구와 서버는 그대로다.

---

## 7. 검증

- 확인 필요: 실습 페이지에서 "힌트 보기" → 1개만 표시 → "다음 힌트 보기"로 하나씩 추가 → 끝까지 펼치면 완료 문구 → 레벨 변경 시 1개로 초기화
