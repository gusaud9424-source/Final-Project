# 02. 힌트 포인트 차감 · 개념 확인 문제 정답 비공개

> 작성: 2026-10-09 · 오현명
> 관련: `01_힌트화면_단계별공개.md`

---

## 1. 요약

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 힌트 | 레벨 힌트를 한꺼번에 내려받고 화면에서 하나씩 보여 줌 (무료) | **한 개씩 서버에서 열고 포인트 차감**: 1번째 5P · 2번째 10P · 3번째부터 20P |
| 다시 보기 | - | 한 번 연 힌트는 무료로 다시 표시 (새로고침 · 레벨 이동 · 재수강 후에도) |
| 포인트 부족 | - | 버튼 비활성 + "포인트가 부족합니다 (출석 · 미션 보상으로 모을 수 있어요)" |
| 안 연 힌트 | 브라우저로 이미 전송됨 (개발자 도구로 미리 볼 수 있었음) | **서버가 보내지 않음** |
| 개념 확인 채점 | 문항별 정답 번호 · 해설 공개 | **맞음 / 틀림 + 점수만** (정답 보기 · 해설 비공개) |

개념 확인 정답을 숨긴 이유: 전용 문항이 없을 때 3회차 퀴즈 문항에서 출제하므로, 정답을 보여 주면 3회차 퀴즈 정답이 미리 노출된다.

## 2. 동작 원리

```
[힌트 보기]  GET  /courses/<과목>/practice/hints?difficulty=<레벨>
              → { total, hints(이미 연 것만), costs:[5,10,20], nextCost, points }

[힌트 열기]  POST /courses/<과목>/practice/hints/reveal { difficulty }
              1) 레벨 잠금 확인 (잠긴 레벨 403)
              2) 사용자 행 잠금(SELECT ... FOR UPDATE) → 동시 클릭으로 잔액 확인이 꼬이지 않게
              3) 다음 번호 = 앞에서부터 연 개수, 비용 = 5 · 10 · 20P
              4) 잔액 < 비용 → 400 "포인트가 부족합니다 (필요 nP · 보유 nP)"
              5) point_ledger 에 -비용 기록 (source="hint", ref="hint:<과목>:<레벨>:<번호>")
                 UNIQUE(user_id, source, ref) → 같은 힌트 중복 차감 불가
              → 갱신된 상태 + 헤더 포인트 즉시 반영
```

- DB 구조 변경 없음 (기존 포인트 장부 사용). 잔액은 장부 합계라 차감이 자동 반영된다.
- 재수강(진도 초기화)해도 장부 기록은 남으므로 이미 산 힌트는 계속 열려 있고 다시 차감되지 않는다.

## 3. 변경 파일

| 파일 | 변경 |
|---|---|
| `backend/app/courses.py` | 힌트 조회(연 것만) · 힌트 열기 API, 비용 규칙, 개념 확인 채점 응답에서 정답 · 해설 제거 |
| `frontend/src/views/ChapterDetailView.vue` | 힌트 열기 버튼(비용 · 보유 포인트 · 부족 안내), 비용 안내 문구 |
| `frontend/src/components/practice/ConceptCheck.vue` | 내가 고른 보기의 맞음/틀림만 표시 |

## 4. 확인

| 상황 | 결과 |
|---|---|
| 0P 에서 힌트 열기 | 400 "포인트가 부족합니다 (필요 5P · 보유 0P)" ✅ |
| 30P → 1번째 · 2번째 열기 | -5P · -10P → 15P ✅ |
| 15P 에서 3번째 | 400 (20P 필요) ✅ |
| 충전 후 3번째 / 다시 열기 | -20P / 409 "모든 힌트를 이미 열었습니다" (추가 차감 없음) ✅ |
| 새로고침 후 | 연 힌트 3개 그대로, 포인트 변화 없음 ✅ |
| 잠긴 레벨 힌트 | 403 ✅ |
| 화면 | "힌트 열기 (1/3) · -5P · 보유 167P" → 열면 162P, 헤더 포인트도 갱신 ✅ |
| 개념 확인 채점 응답 | `id` · `correct` 만 (정답 번호 · 해설 없음), 화면은 고른 보기 초록/빨강 + 점수 ✅ |

브라우저 점검 중 발견해 함께 고친 오류: 힌트 화면에서 포인트 저장소(`profileStore`) 생성 누락 → "힌트가 없습니다"로 보이던 문제.
