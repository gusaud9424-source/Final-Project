# 01. 로고 변경 (CSS3 방패 + Pretendard S)

> 대상: 웹 보안을 처음 배우는 입문자
> 목표: SecuQuest 로고가 어떤 모양으로 바뀌었고, SVG 마스크로 글자를 "뚫어" 표현하는 원리를 이해한다.
> 작성: 2026-10-04 · 오현명

---

## 1. 요약

- **프레임**: CSS3 로고와 같은 방패 비율(가로:세로 ≈ 0.88)로 바꿨다. 기존(40×48)보다 **가로가 넓다**.
- **글자 S**: 헤더 타이틀 "SecuQuest"의 S와 **같은 폰트(Pretendard, 굵기 700)** 로 바꿨다.
- **크기**: 방패 높이의 약 45%로 줄여 방패 가운데에 맞췄다(이전 블록형 S는 약 68%).
- **색상**: 하드코딩 hex 없이 `currentColor` + `var(--sq-color-accent)` 를 그대로 사용한다.
- 수정 파일은 `frontend/src/components/brand/BrandMark.vue` 하나이며, 헤더(AppHeader)와 인증 카드(AuthCard)에 함께 적용된다.

---

## 2. 개념 설명 (비유)

**색종이에 글자 모양으로 구멍을 뚫는 것**과 같다.

- 파란 색종이(방패)를 먼저 깔고,
- 그 위에 "S" 모양 칼틀을 대고 오려낸다(마스크).
- 오려낸 자리로는 뒤 배경이 그대로 비친다. 그래서 배경색이 바뀌어도 S는 늘 자연스럽게 보인다.

---

## 3. 용어 설명

| 용어 | 뜻 |
|---|---|
| SVG | 점·선·면을 좌표로 그리는 벡터 이미지. 확대해도 깨지지 않는다 |
| viewBox | SVG 내부 좌표계. `30 0 452 512` = x 30부터 폭 452, 높이 512 |
| path | 좌표를 이어 도형을 그리는 SVG 요소 (`M` 시작점, `L` 직선, `Z` 닫기) |
| mask | 흰색 부분은 보이고 검은색 부분은 투명하게 만드는 SVG 기능 |
| currentColor | 부모 요소의 CSS `color` 값을 그대로 쓰는 키워드 |
| useId | Vue 3.5 기능. 컴포넌트 인스턴스마다 고유한 id 문자열을 만든다 |

---

## 4. 화면 & 동작

### 4-1. 변경 전 → 변경 후

```
변경 전                      변경 후
┌──────┐                  ┌──────────┐
│  ~S~ │  좁은 방패          │          │  넓은 방패 (CSS3 비율)
│      │  손그림 곡선 S       │    S     │  Pretendard 700 S
 \    /   (모양 불명확)        \        /   (헤더 타이틀과 동일 폰트)
   \/                          \    /
                                 \/
```

### 4-2. 작업 과정

1. 1차: 방패를 CSS3 비율로 넓히고, S를 각진 블록형(두꺼운 path)으로 제작.
2. 2차(최종): 요청에 따라 S를 헤더 "SecuQuest"와 같은 폰트로 바꾸고 크기를 줄여 균형을 맞춤.

### 관련 파일

| 파일 | 역할 |
|---|---|
| `frontend/src/components/brand/BrandMark.vue` | 로고 SVG (방패 path + S 마스크) |
| `frontend/src/components/layout/AppHeader.vue` | 헤더에서 BrandMark 사용 (변경 없음) |
| `frontend/src/components/auth/AuthCard.vue` | 인증 카드에서 BrandMark 사용 (변경 없음) |

## 5. 동작 원리 (SVG 마스크)

```
[방패 path]  M71 460 L30 0 L482 0 L441 460 L256 512 Z
      │  fill="currentColor" → var(--sq-color-accent) 파란색
      ▼
[mask 적용]
      - 흰 사각형(전체 보임)
      - 검은 text "S" (그 부분만 투명)
      ▼
[결과] 파란 방패 안에 S 모양으로 배경이 비쳐 보임
```

핵심 코드:

```vue
<mask :id="maskId" maskUnits="userSpaceOnUse" x="30" y="0" width="452" height="512">
  <rect x="30" y="0" width="452" height="512" fill="white" />
  <text class="sq-brand-mark__letter" x="256" y="372" text-anchor="middle" fill="black">S</text>
</mask>
<path fill="currentColor" :mask="`url(#${maskId})`" d="M71 460 L30 0 L482 0 L441 460 L256 512 Z" />
```

```css
.sq-brand-mark__letter {
  font-family: var(--sq-font-family); /* 헤더 타이틀과 동일 */
  font-weight: 700;
  font-size: 360px; /* viewBox 기준 → 방패 높이의 약 45% */
}
```

### 왜 이렇게 했나

- **폰트 통일**: 로고 S와 옆의 "SecuQuest" 글자가 같은 폰트여야 브랜드가 한 덩어리로 보인다. path로 그리면 폰트와 미묘하게 달라진다.
- **마스크(투명) 방식**: S를 흰색으로 칠하면 hex/색 지정이 필요하고 배경이 바뀌면 어색해진다. 뚫어서 배경을 비추면 색 토큰 규칙도 지키고 어디서나 자연스럽다.
- **고유 마스크 id(useId)**: 한 페이지에 로고가 여러 개 있으면 id가 겹쳐 마스크가 꼬일 수 있어 인스턴스별로 다르게 만든다.
- **크기 45%**: 블록형 S(68%)는 꽉 차서 답답했고, 방패의 평평한 영역 가운데에 들어가도록 줄였다.

---

## 6. 수치 정리

| 항목 | 값 |
|---|---|
| 렌더 크기 | 42 × 48 px (헤더) |
| viewBox | `30 0 452 512` |
| S 폰트 | Pretendard, 700 |
| S font-size | 360 (viewBox 단위) |
| S 위치 | x=256(가운데 정렬), baseline y=372 |

---

## 7. 핵심 정리

- 방패를 CSS3 비율로 넓혀 프레임이 답답하지 않게 했다.
- S는 헤더 "SecuQuest"와 같은 Pretendard 700으로, 방패 높이의 약 45% 크기로 가운데 배치했다.
- SVG 마스크로 S를 뚫어 배경이 비치게 해 색 토큰 규칙(하드코딩 hex 금지)을 지켰다.
