## 1. 감사 로그란

**보안에 영향을 주는 행동의 기록**이다. 사고가 났을 때 "누가 · 언제 · 무엇을 · 누구에게 · 어디서" 했는지 되짚을 수 있어야 한다.

| 질문 | 컬럼 |
|---|---|
| 누가 | `actor_username` · `actor_role` |
| 언제 | `created_at` |
| 무엇을 | `action` · `detail` |
| 누구에게 | `target_username` |
| 어디서 | `ip` |

> 비유: **은행 금고 출입 대장**. 금고를 열 때마다 이름 · 시각 · 목적을 적는다. 대장이 금고 안에 있으면 도둑이 대장도 들고 간다 → 대장은 **따로 보관**한다.

---

## 2. 서버 로그만으로는 왜 부족한가

| 서버 로그만 (변경 전) | DB 보관 (변경 후) |
|---|---|
| 컨테이너를 지우거나 다시 만들면 로그가 사라짐 (`docker compose down`) | DB 볼륨에 남음 |
| 관리자가 보려면 서버 셸 접속 + `grep` | 관리자 화면에서 검색 · 필터 |
| 형식이 글자 한 줄 → 조건 검색 어려움 | 컬럼별 조회 (동작 · 아이디) |

그래서 **두 곳 모두** 남긴다. 서버 로그는 실시간 모니터링용, DB 는 보관 · 조회용.

## 3. 설계에서 지킨 원칙 4가지

### ① 변경과 기록은 한 묶음 (트랜잭션)

```python
user.password_hash = new_hash
record_audit(user, "change_password")   # session.add 만
db.session.commit()                     # 변경 + 기록 함께 저장
```

- 기록을 commit 뒤에 따로 하면 → 중간에 오류가 나면 **"바뀌었는데 기록 없음"**.
- 같은 commit 에 넣으면 → 둘 다 저장되거나 둘 다 취소된다(원자성).
- 실패한 요청(409 등)은 rollback 으로 기록도 사라진다 → **실제로 일어난 일만** 남는다.

### ② 회원이 지워져도 기록은 남는다

- `audit_logs` 에 `users` 외래키를 걸지 않았다. 걸면 회원을 지울 때 기록도 지우거나, 기록 때문에 회원을 못 지운다.
- 대신 **아이디를 기록 시점 값으로 복사**해 둔다(`actor_username`, `target_username`).
- "회원 삭제" 기록이야말로 가장 중요한 기록이다 — 삭제와 함께 사라지면 안 된다.

### ③ 개인정보 값은 기록하지 않는다

```
✅ detail = "fields=name,email"     (무엇이 바뀌었는지)
❌ detail = "email=a@b.com → c@d.com" (값 자체)
```

- 감사 로그는 여러 관리자가 본다. 값을 남기면 로그가 **개인정보 저장소**가 되고, 유출 시 피해가 커진다.

### ④ 믿을 수 있는 값만 기록한다

- IP 는 `request.remote_addr`. `X-Forwarded-For` 헤더는 사용자가 아무 값이나 넣을 수 있어 그대로 믿으면 기록을 조작당한다.
- 행위자는 요청 내용이 아니라 **세션**에서 꺼낸 사용자.

## 4. 조회 API 의 보안

| 위협 | 장치 |
|---|---|
| 학생이 감사 로그 열람 | `_require_admin()` → 403 |
| 검색어로 SQL Injection | `AuditLog.actor_username.like(like)` — SQLAlchemy 가 값을 **바인딩**해 SQL 문법으로 해석하지 않음 (`' OR 1=1--` → 0건) |
| 이상한 동작 값 | `ACTION_LABELS` 에 있는 값만 허용, 아니면 400 |
| 대량 조회로 서버 부하 | 50건씩 페이지, 검색어 80자 제한 |
| 기록 삭제 · 수정 | API 자체가 없음 (조회만) |

> 💡 SQL Injection 실습에서 배운 "문자열을 이어 붙이면 위험, 바인딩하면 안전" 을 우리 서비스 코드에서 그대로 지킨 예.

## 5. 발표용 한 줄 설명

> "관리자 작업과 비밀번호 · 회원정보 변경은 변경과 같은 트랜잭션으로 감사 로그 테이블에 남깁니다. 회원이 삭제돼도 기록은 남고, 개인정보 값은 저장하지 않으며, 관리자 화면에서 검색할 수 있습니다."
