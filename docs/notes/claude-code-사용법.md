# Claude Code 사용법

## 개요
Claude Code는 터미널에서 동작하는 Anthropic 공식 AI 코딩 CLI다. 자연어로 요청하면 파일 읽기/편집/실행, git 조작, 서브에이전트 위임 등을 직접 수행한다.

## 실행
```bash
claude              # 대화형 세션 시작 (현재 디렉토리 기준)
claude "질문 또는 지시"   # 프롬프트를 바로 전달하며 시작
claude --continue  # 가장 최근 세션 이어서 시작
claude --resume     # 세션 목록에서 골라 이어서 시작
```

## 슬래시 명령어 (대화 중 입력)
| 명령어 | 용도 |
|---|---|
| `/help` | 도움말 |
| `/clear` | 대화 컨텍스트 초기화 |
| `/config` | 모델, 테마 등 설정 |
| `/fast` | 빠른 출력 모드 토글 (Opus 계열) |
| `/loop [간격] <명령>` | 명령을 주기적으로 반복 실행 |
| `/security-review` | 현재 브랜치 변경사항 보안 리뷰 |
| `/init` | 프로젝트용 CLAUDE.md 초기 생성 |
| `!<명령어>` | 셸 명령을 세션에서 직접 실행 (출력이 대화에 포함됨) |

## CLAUDE.md — 프로젝트별 지침 파일
프로젝트 루트의 `CLAUDE.md`는 해당 프로젝트에서 항상 자동으로 읽혀 지침으로 적용된다. 코딩 컨벤션, 금지 사항, 토큰 절약 규칙 등을 적어두면 매 세션 반복 설명할 필요가 없다. (이 프로젝트의 `/mnt/c/study/project/Final-Prj/CLAUDE.md` 참고)

## 권한 모드
- 파일 읽기 등 안전한 동작은 자동 허용되지만, 파일 수정·명령 실행처럼 영향이 있는 동작은 실행 전 사용자 승인을 요청한다.
- `.claude/settings.json`에 반복 승인하는 안전한 명령(`git status`, `pytest` 등)을 allowlist로 등록하면 매번 묻지 않는다 (`/fewer-permission-prompts`로 자동 스캔 가능).
- `rm -rf`, `git push --force`, DB 파괴 쿼리 등 파괴적 명령은 allowlist에 넣지 않는 것을 권장.

## 서브에이전트 (Agent)
- 탐색/조사처럼 결과 요약만 필요하고 중간 과정은 필요 없는 작업은 서브에이전트에 위임해 메인 대화의 컨텍스트를 절약한다.
- 예: "이 함수를 어디서 쓰는지 전부 찾아줘" → Explore 에이전트가 검색 후 요약만 반환.
- `fork`는 현재 대화 맥락을 그대로 이어받는 서브에이전트로, 결과만 필요하고 과정은 컨텍스트에 남기고 싶지 않을 때 사용.

## Plan 모드
복잡한 구현 작업 전에 계획을 먼저 세우고 사용자 승인을 받는 모드. 큰 변경을 시작하기 전에 방향을 맞추는 데 사용.

## 메모리 (Memory)
세션 간에 유지되는 파일 기반 기록. 사용자 선호, 프로젝트 맥락, 반복되는 피드백 등을 저장해 다음 대화에서도 참고한다. 명시적으로 "기억해줘"라고 요청하면 즉시 저장된다.

## Git 연동
- `git status`/`git diff`/`git log`를 확인한 뒤에만 커밋 생성 (명시적으로 요청받았을 때만 커밋)
- PR 생성 시 `gh pr create` 사용, 커밋/PR 전 스테이징 내용에 `.env`나 자격증명이 포함되지 않았는지 확인

## Artifact / Workflow (참고)
- **Artifact**: 웹페이지(HTML) 형태의 산출물을 발행해 브라우저에서 바로 확인 가능하게 하는 기능. 대시보드, 목업 등에 사용.
- **Workflow**: 다수의 서브에이전트를 조합해 오케스트레이션하는 기능. 비용이 크므로 사용자가 명시적으로 요청("ultracode" 등)했을 때만 사용.

## 이 프로젝트에서의 활용 팁
- 취약점 학습 플랫폼 특성상, 의도된 취약 코드는 리뷰 중 발견해도 임의로 고치지 않도록 `CLAUDE.md`에 규칙이 명시되어 있음 — 새 세션에서도 자동 적용됨.
- 토큰 절약을 위해 파일 전체 대신 `grep`/`offset`/`limit`로 필요한 부분만 확인하도록 지침이 설정되어 있음.
